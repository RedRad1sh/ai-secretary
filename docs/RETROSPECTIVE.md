Проект: Telegram-бот «AI-секретарь» — текст/голос/пересылка/фото → черновик
события (предпросмотр) → Google Calendar или .ics + напоминания. Мульти-доступ

## 1. Что реализовано

### Ядро и этапы 1–2 (PR #1 → master)
- Извлечение событий: LLM (OpenAI-совместимый контракт / GigaChat) → строгий
  JSON → валидация в `EventDraft`; каскадный офлайн-фолбэк (dateparser +
  ручной разбор dd.mm[.гггг] + rutimeparser) с честным предупреждением
  «Локальный разбор…» в карточке.
- Стабилизация LLM (этап 1): бюджет 35 с на весь запрос, токен-лимиты
  4096/8192, ретраи с backoff на 429/5xx, фолбэк по списку моделей,
  rate-limiter 18 RPM, авто-откат JSON-режима, отсутствие «случайной даты
  соседнего события», диапазоны «с 10:00 до 11:30» и через полночь не
  разваливаются на два события.
- Google Calendar OAuth (этап 2) — **отложен**: обработчикам передаётся
  `gcal=None`, работает fallback-экспорт .ics + кнопка «Открыть в Google
  Календаре» (ссылка), TZID Moscow.
- Мульти-доступ: `ALLOWED_USER_IDS` / `PAID_USER_IDS`, изоляция БД
  `users/<ID>.db` (события, история, `/undo`, `/stats`, настройки, напоминания),
  платный шлюз для пакетов/повторов/OCR/`/today`/`/tomorrow`/переноса-отмены.
- Функции этапа 4: пакеты из одного сообщения («Создать все»), RRULE-повторы
  с напоминаниями на вхождениях, `/today`/`/tomorrow`, перенос и отмена текстом
  (длительность сохраняется, напоминания перепланируются/отменяются, включая
  legacy-строки `event_pk=NULL`), OCR Tesseract rus+eng (до 5 МБ, таймаут 20 с,
  платный whitelist), `/list`, `/settings`, `/undo`, `/stats`.

## 4. Ограничения, которые остались (честный список)

- **Google OAuth отложен** (этап 2): экспорт только .ics/ссылка; персональная
  авторизация — этап 5.
- **FSM в памяти**: неподтверждённые карточки теряются при рестарте (ожидаемо,
  зафиксировано в приёмке 7.4).
- **Доставка at-least-once**: дубль возможен при падении между send и записью
  в БД; один процесс; «ответ ≤5 с» не гарантируется.
- **Повторы**: без UNTIL/COUNT/исключений; сложные условия могут не
  распознаваться локальным парсером.
- **OCR**: только фото (не PDF/видео), качество зависит от снимка; A8/A9
  реально прогоняются только с tesseract.
- **#13**: ветка «уточняющий вопрос вместо генерации» не реализована (критерий
  допускает «либо/либо»); «дни/раскол» зависят от честности модели (prompt +
  `assumptions`), код гарантирует маркировку времени/длительности; серии
  детектируются по заголовку+описанию.
- **STT**: отдельный бесплатный провайдер (Groq whisper, ~2000 req/день);
  длинные голосовые не поддерживаются.
- **Монетизация**: ручные whitelist'ы, без платежей/квот/подписок (этап 5).
- **Хостинг**: на Netrun free-тарифе бот живёт 3 часа после запуска —
  постоянная работа требует VDS/платного тарифа (по плану — один polling-
  процесс Docker с `restart: unless-stopped`).
