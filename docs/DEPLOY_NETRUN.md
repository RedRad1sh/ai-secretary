# 🚀 Деплой на Netrun (netrun.io)

Netrun — российская PaaS: загружаете код, она сама собирает и держит его в работе,
без VPS и настройки. Оплата рублями (карта/СБП), поддержка на русском.

## ⚠️ Честно про бесплатный тариф

| | |
|---|---|
| Сайты на free | живут постоянно (спят при простое, просыпаются по запросу) |
| **Боты на free** | **работают 3 часа после запуска**, дальше останавливаются до Pro (цена — в кабинете, тариф «Pro», оплата за срок) |
| Хранилище | папка `/data` персистентна: БД, напоминания и логи переживают перезапуски и обновления кода |

Вывод: **бесплатный тариф Netrun подходит для теста**, а для 24/7 нужен Pro
(или альтернативы за 0 ₽: локальный режим / YC Functions + Timer-триггер).

## Что уже подготовлено

В репозитории есть `scripts/build_netrun_zip.py` — собирает `netrun-bot.zip`:
пакет `bot/` + `requirements.txt` + **Dockerfile**, в котором прописано
`ENV DATA_DIR=/data` (чтобы БД с напоминаниями жила в персистентной папке)
и запуск long polling-ом (`python -m bot.main`) — вебхуки и домен боту не нужны.

```bash
python scripts/build_netrun_zip.py   # -> netrun-bot.zip
```

## Пошагово

1. **Соберите архив** командой выше.
2. Зарегистрируйтесь на https://netrun.io → **New project / Новый проект**.
3. Источник кода: **Upload** → загрузите `netrun-bot.zip`.
4. Netrun увидит Dockerfile и соберёт проект (или определит Python сам).
5. **Секреты (Secrets)** — добавьте переменные:

   | Переменная | Значение | Обязательна |
   |---|---|---|
   | `BOT_TOKEN` | токен от @BotFather | ✅ |
   | `ALLOWED_USER_ID` | ваш числовой Telegram ID | ✅ |
   | `LLM_API_URL` | URL OpenAI-совместимого API (примеры в `.env.example`) | ✅ или GigaChat |
   | `LLM_API_KEY` | ключ провайдера | с URL |
   | `LLM_MODEL` | имя модели | с URL |
   | `GIGACHAT_API_KEY` / `GIGACHAT_SCOPE` | альтернатива: нативный GigaChat | опция |
   | `DEFAULT_TIMEZONE` | `Europe/Moscow` | нет |
   | `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` / `GOOGLE_REFRESH_TOKEN` | автосоздание в Google Календаре | нет (иначе .ics) |
   | `LLM_VOICE_MODEL` / `LLM_STT_ENABLED` | распознавание голосовых | нет (по умолч. вкл) |

6. **Launch** → смотрите вкладку **Logs**: должно появиться
   `Бот запущен. Google Calendar: ...` и `Start polling`.
7. Напишите боту в Telegram — придёт карточка события.

## Важные нюансы

- **Вебхук выключится сам**: наш `main.py` при старте делает `delete_webhook`
  и переходит в polling. Но если до этого был активен webhook на YC — Yandex-функция
  больше сообщений не получает, конфликтов нет.
- **Одновременно два инстанса нельзя**: локальный запуск и Netrun вместе будут
  конфликтовать за polling. Перед запуском на Netrun остановите локального бота.
- **База и напоминания**: живут в `/data` (персистентна). Обновление кода
  (новый ZIP) их не трогает — в отличие от файлов вне `/data`.
- **Ссылка** `имя.netrun.io` боту не нужна (polling), но пригодится для проверки.
- Перезапуск при падении и алерты — со стороны Netrun; логи — вкладка Logs.

## Обновление бота

Правите код → `python scripts/build_netrun_zip.py` → в панели Netrun загрузить
новый ZIP (Update). `/data` сохраняется.

## Если что-то не работает

| Симптом в Logs | Причина |
|---|---|
| `BOT_TOKEN не задан` | Секрет `BOT_TOKEN` не добавлен/опечатка |
| `Unauthorized` | Неверный токен бота |
| `ALLOWED_USER_ID не задан — бот будет отвечать всем` | Не добавили секрет |
| Бот запустился и через 3 часа замолчал | Лимит free-тарифа: bot живёт 3 ч → нужен Pro |
| `AI не настроен` / `GigaChat вызов упал` | Не заданы LLM_*/GIGACHAT_* или неверный ключ; бот продолжает работать офлайн-парсером |
